A LITTLE STORY, MADE FOR YOU
Contains index.html, style.css, script.js, 10 photos and the provided Until I Found You audio file.
For GitHub Pages, upload the contents of this folder to the repository root and preserve the assets folder paths.
The audio starts only after a user interaction because browsers commonly block autoplay. Fonts load from Google Fonts; fallbacks are included.
Please ensure you have permission to use the supplied music in any public or commercial promotional release.
